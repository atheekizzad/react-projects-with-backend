# 🎨 Avatar Generator with DiceBear and React

A simple **React-based Avatar Generator** that uses the [DiceBear Avatars API](https://www.dicebear.com/) to create customizable avatars in different styles and formats.

## 🚀 Features

- Generate avatars using multiple **styles (sprites)** like `avataaars`, `bottts`, `pixel-art`, and more.
- Supports multiple **output formats**: `SVG`, `PNG`, `JPG`, `WEBP`, and `AVIF`.
- Choose custom **avatar sizes** (16px → 256px).
- Option to **flip avatars horizontally**.
- **Download avatars** with a single click.
- Built with **React** and **react-icons**.
